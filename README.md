# 利率债 · 每日观察

在 Windows 本机浏览器中查看银行间国债、国开债、农发债和进出口行债的每日成交行情快照。手动采集，历史保存在本地，可按券种、代码、名称和期限筛选并导出 Excel / CSV。

## 网页分享版

GitHub Pages 版支持日期、券种和期限筛选，点击代码查看个券走势，并导出筛选后的 CSV。站点提供 `data/latest.json`、`data/index.json` 和 `data/YYYY-MM-DD.json`，供其他页面读取。首次发布使用有明确标注的模拟行情。

发布设置见[上线说明](PUBLISH.md)。GitHub Actions 提供手动发布入口。接入有公开分发授权的行情后，每天北京时间 20:37 自动更新。

## 本机启动与使用

1. 双击本目录的 **Start.cmd**，浏览器将打开 `http://127.0.0.1:8851`。
2. 点击 **采集最新行情**。首次建立官方代码清单可能需要数分钟；此后同一天复用已校验的清单。
3. 在左侧选择日期和筛选条件。表格的下载按钮只导出当前筛选结果。
4. 在“个券轨迹”查看已积累历史；在“数据质量与采集记录”查看缺失字段、待确认分类和失败原因。
5. 双击 **Stop.cmd** 停止本地服务。仅关闭浏览器不会停止后台服务。

应用只监听 `127.0.0.1`，不要求账户或数据服务 API Key。不会自动定时抓取，浏览筛选也不会访问行情接口。建议在每日晚间固定时段手动采集。漏采日期暂不承诺可以从公开源补回。

## 数据口径

- 来源：[中国货币网现券市场成交行情](https://www.chinamoney.com.cn/chinese/mkdatabond/)。读取该公开页面使用的结构化数据接口，不模拟登录或绕过访问限制。
- 券种依据官方债券信息查询中的类型和发行人确认，债券代码始终按文本保存。附息、贴现、特别国债以及三家机构的政策性金融债，在来源有相应行情且分类确认时均可纳入。
- 这是**采集时点的成交行情快照**，不标为正式收盘价，也不保证全市场所有成交覆盖。净价单位为元、收益率为百分数、涨跌为 BP；交易量忠实采用来源的“亿”口径，不换算成成交金额。
- 行情日期取来源发布的完整日期；另存个券更新时间、来源更新时间和本机北京时间。旧日期不改记成今天。
- 来源字段未披露时保留空值。未取得某只债的记录不等于它没有成交。旧行情、更新时间未披露的记录会标记，并从趋势线中排除。
- 趋势图横轴按自然日展示；休市和未采集日期保留缺口。首日只有一个点属正常现象。
- 同一来源日期采用来源更新时间最新的成功批次；时间相同取最新采集批次。不同批次的累计交易量不相加。较新批次没有某只券时，不从上一批次回填。
- 源站同一批次可能重复返回同代码：已披露字段一致时只补齐空字段，保留有披露的交易量，不求和；目标债券的价格、收益率或时间等已披露字段冲突时拒绝发布。基础清单的同代码记录须有一致的官方券种及发行人，才按最新发行记录建立映射。所有原始记录保留以便追溯。
- 官方代码清单每天首次采集刷新。刷新失败且已有缓存时允许使用旧清单并显示警告；首次没有可靠清单时不发布行情。疑似目标券未能确认分类的记录单列，未计入目标数据。
- 源站字段、日期、数值和分页校验不通过，或请求失败时，保留此前成功结果和失败原因。网络请求最多尝试三次；访问拒绝不反复尝试。

## 本地数据和备份

`data/bonds.sqlite3` 保存债券清单、采集记录和快照。`data/raw/` 保存每次行情原始响应与清单原始分页；包含来源和采集时间。Excel 导出会保留债券代码前导零，CSV 导入 Excel 时需将代码列设为文本。

停止应用后，复制整个 `data` 文件夹即可备份。`BOND_DATA_DIR` 环境变量可指定另一数据目录。数据库不依赖浏览器缓存，重启应用后仍可查询。

## 环境与命令

当前项目使用独立 `.venv`，依赖锁定于 `requirements.txt`，可调整版本范围记录在 `requirements.in`。环境为 Python 3.12；移到另一台电脑需重新建立虚拟环境，不直接复制 `.venv`。

```powershell
# 重建环境（指定本机 Python 3.11+；无需更改系统执行策略）
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -PythonPath C:\Python312\python.exe

# 独立运行采集，供未来定时任务复用
.\.venv\Scripts\python.exe -m bonddesk collect

# 查看本地状态
.\.venv\Scripts\python.exe -m bonddesk status

# 自动化测试，不访问真实行情网站
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

首次环境使用 Codex 随附的 Python 创建。如果该基础运行时被卸载或路径失效，需要以可用 Python 重建 `.venv`；数据文件不受影响。

## 验收与试运行

自动化测试覆盖四类分类、前导零、缺值、日期冲突、重复采集、失败保留、旧清单提示、并发任务、导出安全和历史缺口。另对真实来源取样并检查浏览器流程。

连续 3 个交易日的手动试运行是后续使用验收：核对来源日期、四类覆盖、交易量缺失情况以及失败记录。单日成功不等于长期可用；如公开来源停止披露关键字段，页面会展示缺失或失败，需重新评估来源。

首版不含交易所行情、逐笔明细、多年历史回补、定时任务或云端部署。
